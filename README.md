# 무담 부스 게임 — 같은 색에 멈출 수 있나요

캠핑 컨벤션 무담(MOODAM) 부스에서 쓰는 색상 맞추기 게임.
인터넷 없이 **HTML 파일 하나**로 돌아간다.

- 화면 속 무담 램프가 색상환을 돈다. 목표 색에서 탭해 멈춘다
- **2라운드, 100점 만점** (라운드당 50점, 오차 180°면 0점)
- 하루 **TOP 3**에게 무담 미니 LED 클릭커를 준다
- 이름·휴대폰 번호·개인정보 동의를 게임 안에서 직접 받는다

---

## 부스에서 쓰는 법

`무담게임.html` 을 **더블클릭**한다. 끝이다. 와이파이가 없어도 된다.

### 매일 마감할 때 — 이것만은 꼭

**화면 좌측 상단 모서리를 5번 연타** → 운영자 패널 → **`오늘 CSV`** 를 눌러 기록을 내려받는다.

이걸 빠뜨리면 당첨자가 사라진다. 기록은 그 브라우저 안에만 있다.

### 운영 수칙

| 하지 말 것 | 이유 |
|---|---|
| 기기를 두 대 쓰기 | 기록이 기기별로 갈라져 랭킹이 둘로 쪼개진다 |
| 시크릿 모드로 열기 | 창을 닫는 순간 기록이 전부 날아간다 |
| 브라우저 데이터 삭제 | 같은 이유 |
| 행사 중 다른 브라우저로 열기 | 같은 이유 |

충전기를 꽂아 두고, 기기 설정에서 자동 잠금을 꺼 둔다.

### 운영자 패널

좌측 상단 모서리 5번 연타로 열린다.

- 오늘 / 전체 **CSV 내보내기**
- 잘못된 기록 개별 삭제
- **난이도 조정** — 색이 도는 속도(도/초). 점수가 위쪽에 몰리면 올린다
- 날짜 수동 지정 (자정을 넘겨 운영할 때)
- 전체 기록 삭제

> 행사가 끝나면 CSV를 안전한 곳에 옮긴 뒤 **전체 기록 삭제**를 눌러 기기에서 개인정보를 지운다.

## 고치는 법

`src/index.html` 을 고친 뒤:

```bash
./build.sh
```

이미지를 base64로 박아 넣어 `무담게임.html` 과 `index.html` 을 다시 만든다. 둘은 같은 내용이고, `index.html` 은 웹 호스팅용이다.

### 자주 건드릴 설정

`src/index.html` 상단 `CFG`:

| 상수 | 기본값 | 뜻 |
|---|---|---|
| `ROUNDS` | `2` | 한 판의 라운드 수 |
| `SPEED` | `[120, 180]` | 라운드별 색이 도는 속도 (도/초) |
| `PER_ROUND` | `50` | 라운드 만점 |
| `WINNERS` | `3` | 하루 당첨 인원 |
| `MAX_PLAYS` | `1` | 1인당 하루 판수 |
| `CONSENT_PRECHECKED` | `true` | 동의 체크박스를 미리 켜 둘지 |

## 구조

```
무담게임.html    부스에서 여는 파일 (단독 실행)
index.html       같은 내용, 웹 호스팅용
src/index.html   원본. 여기를 고친다
build.py         이미지를 박아 넣어 위 두 파일을 만든다
assets/web/      게임에 들어가는 이미지
docs/            설계 문서
```

기록은 브라우저 `localStorage`의 `moodam.plays.v1` 에 쌓인다.
한 건이 약 110바이트라 한도 5MB 기준 **4만 건**까지 들어간다.
