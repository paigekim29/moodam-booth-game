# 무담 부스 게임 — 같은 색에 멈출 수 있나요

캠핑 컨벤션 무담(MOODAM) 부스에서 쓰는 색상 맞추기 게임.
인터넷 없이 **HTML 파일 하나**로 돌아간다.

- 램프 두 개가 나란히 선다. 왼쪽이 **맞출 색**, 오른쪽이 색상환을 도는 **지금 색**. 같은 색이 됐을 때 탭해 멈춘다
- **2라운드, 100점 만점** (라운드당 50점, 오차 180°면 0점)
- **1인 1판.** 같은 번호로 두 번째 시도는 막힌다
- 이름·휴대폰 번호·개인정보 동의를 게임 안에서 직접 받는다 (구글폼 없음)

### 상품

| 순위 | 상품 |
|---|---|
| 1위 | 무담 조명 **랜덤 발송** |
| 2·3위 | 무담 미니 LED 클릭커 |

하루 **3명**에게 준다. 참가자가 몇 명이든 당첨자는 정확히 3명이라 상품이 모자라거나 남지 않는다.

---

## 부스에서 쓰는 법

`무담게임.html` 을 **더블클릭**한다. 끝이다. 와이파이가 없어도 된다.

### 매일 마감할 때 — 이것만은 꼭

**화면 좌측 상단 모서리를 5번 연타** → 운영자 패널 → **`오늘 CSV`** 를 눌러 기록을 내려받는다.

이걸 빠뜨리면 당첨자가 사라진다. 기록은 그 브라우저 안에만 있다.

### 운영 수칙

| 하지 말 것 | 이유 |
|---|---|
| 기기를 두 대 쓰기 | 기록이 기기별로 갈라져 랭킹이 둘로 쪼개진다 |
| 시크릿 모드로 열기 | 창을 닫는 순간 기록이 전부 날아간다 |
| 브라우저 데이터 삭제 | 같은 이유 |
| 행사 중 다른 브라우저로 열기 | 같은 이유 |

충전기를 꽂아 두고, 기기 설정에서 자동 잠금을 꺼 둔다.

기록을 저장할 수 없는 브라우저(시크릿 모드 등)로 열면 **첫 화면에 경고가 뜬다.** 그 경고가 보이면 그대로 진행하지 말고 일반 창으로 다시 연다.

### 빌린 기기로 운영할 때

행사 랩탑이 본인 것이 아니라면 이렇게 한다.

1. 그 기기에서 배포 주소에 접속한다
2. `Cmd+S` / `Ctrl+S` 로 `무담게임.html` 을 저장한다. 이미지가 파일 안에 전부 박혀 있어 HTML 한 개만 저장하면 된다
3. **와이파이를 끄고** 저장한 파일을 열어 동작을 확인한다
4. 운영자 패널에서 **전체 기록 삭제**로 테스트 데이터를 지운다
5. 행사 3일 내내 그 파일만 연다

행사가 끝나면 CSV를 옮긴 뒤 **전체 기록 삭제**를 반드시 누른다. 남의 기기에 실명과 전화번호를 남기지 않는다.

### 운영자 패널

좌측 상단 모서리 5번 연타로 열린다.

- 오늘 / 전체 **CSV 내보내기**
- 잘못된 기록 개별 삭제
- **난이도 조정** — 색이 도는 속도(도/초). 점수가 위쪽에 몰리면 올린다
- 날짜 수동 지정 (자정을 넘겨 운영할 때)
- 전체 기록 삭제

> 행사가 끝나면 CSV를 안전한 곳에 옮긴 뒤 **전체 기록 삭제**를 눌러 기기에서 개인정보를 지운다.

## 고치는 법

`src/index.html` 을 고친 뒤:

```bash
./build.sh
```

이미지를 base64로 박아 넣어 `무담게임.html` 과 `index.html` 을 다시 만든다. 둘은 같은 내용이고, `index.html` 은 웹 호스팅용이다.

### 자주 건드릴 설정

`src/index.html` 상단 `CFG`:

| 상수 | 기본값 | 뜻 |
|---|---|---|
| `ROUNDS` | `2` | 한 판의 라운드 수 |
| `SPEED` | `[120, 180]` | 라운드별 색이 도는 속도 (도/초) |
| `PER_ROUND` | `50` | 라운드 만점 |
| `WINNERS` | `3` | 하루 당첨 인원 |
| `MAX_PLAYS` | `1` | 1인당 하루 판수 |
| `CONSENT_PRECHECKED` | `true` | 동의 체크박스를 미리 켜 둘지 |

> 개인정보 동의 체크박스는 기본으로 켜져 있다. 국내 개인정보보호법상 사전 체크된 동의는 유효성 논란이 있으므로, 법무 검토 결과에 따라 `false` 로 바꾼다.

입력 칸은 **자동완성을 꺼 두었다.** 켜져 있으면 다음 참가자가 이름 칸을 눌렀을 때 앞사람의 이름과 전화번호가 자동완성 목록에 뜬다. 표준 필드명(`name`, `tel`)을 쓰면 브라우저가 `autocomplete="off"` 를 무시하므로 필드명 자체를 무의미한 값으로 두었다. 건드리지 않는다.

## 구조

```
무담게임.html    부스에서 여는 파일 (단독 실행)
index.html       같은 내용, 웹 호스팅용
src/index.html   원본. 여기를 고친다
build.py         이미지를 박아 넣어 위 두 파일을 만든다
assets/web/      게임에 들어가는 이미지
docs/            설계 문서
```

`assets/web/` 에 들어가는 이미지는 네 개다.

| 파일 | 쓰이는 곳 |
|---|---|
| `unit.png` | 게임 램프. 투명 배경이어야 한다. 색은 CSS 로 입히므로 **흰색 원본**을 쓴다 |
| `logo.png` | 대기 화면 상단. 흰색 + 투명 배경 |
| `prize.png` | 2·3위 상품 (클릭커 3색) |
| `prize1.png` | 1위 상품. 랜덤 발송이라 물음표 램프 |

램프 이미지를 바꿀 때는 **배경이 투명한 흰색**이어야 한다. 색이 들어간 사진을 쓰면 CSS 로 입히는 색과 섞여 의도한 색이 나오지 않는다.

기록은 브라우저 `localStorage`의 `moodam.plays.v1` 에 쌓인다.
한 건이 약 110바이트라 한도 5MB 기준 **4만 건**까지 들어간다.
